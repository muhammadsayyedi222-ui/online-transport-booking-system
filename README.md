# Online Road Transport Booking System

A web-based online road transport booking system developed as a final-year Computer Science project. The system is designed to make bus ticket booking more convenient by allowing users to view available routes, book trips, and manage their bookings online.

## Project Overview

The Online Road Transport Booking System provides a digital platform for managing road transport reservations. It includes a user-facing booking system and an administrative dashboard for managing routes, prices, bookings, and users.

## Key Features

### User Features

* User registration and login
* Browse available transport routes
* Select origin and destination
* View ticket prices
* Book available trips
* Select seats
* View booking information
* Mock payment functionality
* Booking confirmation

### Admin Features

* Secure admin login
* Admin dashboard
* Manage transport routes
* Manage route prices
* View and manage bookings
* Approve or reject bookings
* Manage users
* Monitor booking activities

## Installation and Setup

1. Download or clone this repository.

2. Install and start **Apache** and **MySQL** using XAMPP.

3. Copy the project folder into:

   `C:\xampp\htdocs\`

4. Open **phpMyAdmin**.

5. Create a database for the project.

6. Import the provided `database.sql` file.

7. Check the database connection settings in `db.php`.

8. Open the project in your browser using:

   `http://localhost/transport_booking_final/`
